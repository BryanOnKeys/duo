# Discovery channels and approval gates

Nothing on this page has been submitted or posted. Every listing pull request, community post, e-mail, DM or public recruitment needs the maintainer's explicit approval first. Drafts are not approval.

| Channel | Requirements checked on 2026-10-19 | Fit | Next step |
|---|---|---|---|
| [awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) | Public repository that users can install and run. One line in the right category, alphabetical, format `- [name](repo) - description`, via a pull request ([CONTRIBUTING](https://github.com/punkpeye/awesome-mcp-servers/blob/main/CONTRIBUTING.md)) | High: stdio MCP server installed from npm | Owner approval, then one pull request |
| [MCP Registry](https://github.com/modelcontextprotocol/registry) | Published with the `mcp-publisher` CLI and a `server.json`. npm packages need an `mcpName` marker for verification; `io.github.<user>/*` names must match the GitHub login | High | Needs a package change and a release; decide separately |
| [Show HN](https://news.ycombinator.com/showhn.html) | Something you made that people can try. Not a landing page, a list or a minor version announcement. The author answers questions | Fits as a project introduction | Owner posts and answers. Never coordinate upvotes |
| [DEV Community](https://dev.to) | Technical article with a reproduction and limits | Fits | Owner posts |
| [GeekNews](https://news.hada.io) (Show GN) | Rules not checked yet | Unknown | Check the rules at submission time |
| Reddit | Rules differ per subreddit | Unknown | Pick one subreddit only after reading its self-promotion rules |

Before any post, re-check: the published version, the install commands, the supported rule scope, the demo output, the open issues and any real external findings. Do not claim guaranteed safety, token or cost savings, complete compliance checking or an independent validation that has not happened.
